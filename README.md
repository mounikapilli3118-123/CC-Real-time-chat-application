# Real-Time Chat Application

## 📌 Project Overview
The **Real-Time Chat Application** is a web-based platform developed to enable instant communication between registered users. It provides a simple and user-friendly interface where users can connect with contacts, exchange messages, and manage their profiles.

The application is developed using **React.js** for the frontend and **Firebase** for authentication and real-time data management.

## 🎯 Objectives
- Provide secure user registration and login.
- Enable real-time communication between users.
- Allow users to view contacts and start conversations.
- Store and manage messages using Firebase Realtime Database.
- Maintain user availability status.
- Provide notifications for communication activities.
- Offer a simple and interactive user interface.

## 🗄️ Database Structure

The application uses Firebase Realtime Database with the following main nodes:

| Node | Description |
|---|---|
| `users` | Stores user information |
| `messages` | Stores messages exchanged between users |
| `status` | Maintains user availability status |
| `notifications` | Stores notification information |

Firebase Realtime Database synchronizes data dynamically, allowing updates to appear in the application in real time.

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/mounikapilli3118-123/CC-Real-time-chat-application.git
   ```

2. Navigate to the project folder:

   ```bash
   cd CC-Real-time-chat-application
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

   If your project uses Vite, run:

   ```bash
   npm run dev
   ```
